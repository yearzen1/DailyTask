# 管理任务

> 类型：操作指南
> 状态：稳定
> 适用版本：v0.1.9+
> 相关：reference/tasks-and-intervals.md、reference/checkins.md

适用：新建任务、停用、重新启用、设置每 N 天、删除任务。

---

## 1. 新建任务

1. 左侧「任务管理」。
2. 点「＋ 新任务」。
3. 填名称、类型、启用日期、可选截止日期、间隔天数。
4. 点「创建」。

启用日期默认今天；间隔 `1` 表示每天。截止日期留空表示一直有效；设了截止日期后，任务只在截止日（含）之前出现。

## 2. 设置每 N 天

新建或编辑任务时，间隔天数填 `N`：

- 以启用日为第 1 天
- 第 1、N+1、2N+1… 天出现
- 非周期日不会出现在今日，任务表格子禁用，统计不计入

## 3. 停用任务

1. 行尾点「停用」。
2. 选生效日期（不能早于今天，也不能早于本段启用日）。
3. 确认。

停用日期含当天：选今天表示今天仍生效，明天起不再出现。

## 4. 重新启用

1. 已停用行点「重新启用」。
2. 选生效日期（不早于上一段结束日次日）。
3. 确认。

会追加新一段区间，历史段和打卡不变；新段继承上一段间隔天数。

## 5. 编辑任务

1. 行尾点「编辑」。
2. 可改名称、类型、最新一段起止日期、间隔天数。
3. 更早区间只读。
4. 点「保存」。

校验：

- 启用日期必填
- 截止日期 ≥ 启用日期
- 新段启用日必须晚于上一段结束日

## 6. 删除任务

1. 行尾点「删除」。
2. 确认框写明会删除区间与全部打卡。
3. 点「确认删除」。

删除不可恢复；失败会保留弹窗并提示。

## 7. 验证

- 任务表出现/消失
- 今日页按新周期显示
- 停用后历史可见但格子不可点
- 删除后统计与挂件同步

## 8. 注意

- 不要用「编辑」改历史段；历史段只读
- 删除任务前先备份（见 backup-and-restore）
