# 管理待办

> 类型：操作指南
> 状态：稳定
> 适用版本：v0.1.9+
> 相关：reference/todos.md、how-to/daily-use.md

适用：新增待办、改日期、重命名、完成、删除。

---

## 1. 新增待办

1. 左侧「待办」。
2. 顶部输入标题。
3. 可选截止日期；不填归入「以后」。
4. 按回车或点「添加」。

需要多行标题时按 `Shift+Enter` 换行，`Enter` 仍然保存。

## 2. 分组

- 逾期
- 今天
- 本周（周日为界）
- 以后
- 已完成（默认折叠）

未完成且截止日在未来的待办会显示「还差 N 天」；今天和逾期仍显示原有 chip。

## 3. 改截止日期

方式一：行内日历

1. 悬停待办行。
2. 点 `✎` 和 `✕` 之间的日历按钮，直接弹出日历。
3. 点一个日期即保存并关闭；点底部「清除」可清空截止日。

方式二：右键

1. 右键待办行。
2. 修改日期。
3. 保存 / 清除日期。

## 4. 重命名

1. 悬停行，点 `✎`。
2. 输入新名字；`Shift+Enter` 可换行。
3. `Enter` 或失焦保存，`Esc` 取消。

## 5. 完成 / 取消完成

- 点左侧圆圈完成
- 再点一次取消完成
- 今日页和挂件也可以点行完成；当天勾选的待办会保留到当天结束，次日自动消失

## 6. 删除

1. 点行尾 `✕`，或右键 →「删除待办」。
2. 确认框点「确认删除」。

删除不可恢复；失败会保留弹窗并提示。

## 7. 验证

- 分组随日期变化
- 已完成项默认折叠
- 今日页/挂件同步
- 删除后不可恢复
