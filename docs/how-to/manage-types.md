# 管理任务类型

> 类型：操作指南
> 状态：稳定
> 适用版本：未发布
> 相关：reference/tasks-and-intervals.md、how-to/manage-tasks.md、reference/data-model.md

适用：新建类型、嵌套子类型、调整顺序、改名、删除，以及给某个类型直接加任务。

---

## 1. 打开类型页

左侧导航「类型」。页面是一棵树，缩进表示层级；每行显示色点、名称和任务数。选中类型后，在底部详情区查看信息和操作。

「自愿」「被迫」只是初始的两个默认类型，之后行为与自定义类型一致：

- 可改名、可拖动、可嵌套
- 可删除，但有任务或子类型时需先移走
- 至少要保留一个类型

## 2. 新建类型

1. 点右上角「＋ 新类型」。
2. 填名称，上级类型留空表示顶层。
3. 选颜色，点「创建」。

在类型行上点「＋ 子类型」会预选当前类型为上级。

## 3. 类型嵌套

- 新建时选择上级类型，或在编辑弹窗里改「上级类型」。
- 也可以直接拖动类型：拖到目标行中间，就成为它的子类型。
- 不能选择自己或自己的子孙作为上级。
- 同一父级下类型名不能重复。
- 层级没有硬性上限，界面按缩进显示。

## 4. 排序

- 拖动类型行左侧的手柄。
- 拖到目标行的上边缘：插到目标前面，同级。
- 拖到目标行的下边缘：插到目标后面，同级。
- 拖到目标行的中间：成为目标的子类型，追加到末尾。
- 非法落点会显示禁止提示，不会改数据。

## 5. 给类型加任务

1. 选中类型，在底部详情区点「＋任务」。
2. 弹窗列出不在当前类型及其子类型下的任务。
3. 勾选一个或多个任务，可搜索、全选 / 清空。
4. 点「添加 N 个」。

选中的任务会从原类型移入当前类型；一个任务只能属于一个类型。任务页不再提供新建任务入口，新建任务请去「任务管理」。

## 6. 改名与颜色

1. 选中类型，在底部详情区点「编辑」。
2. 改名称、上级类型或颜色。
3. 点「保存」。

未改名的「自愿 / 被迫」跟随界面语言显示；设置自定义颜色后优先使用自定义颜色。

## 7. 删除类型

1. 选中类型，在底部详情区点「删除」。
2. 确认弹窗里点「确认删除」。

限制：

- 有直属任务：先把任务改到别的类型
- 有子类型：先删除或移走子类型
- 至少要保留一个类型
- 只有空类型可以删除

## 8. 折叠

今日页、任务表、挂件都按类型分组：

- 点组头折叠 / 展开
- 折叠父类型时，所有子类型一起隐藏
- 折叠状态不持久化：切视图或重启后恢复展开；挂件回到胶囊再展开时全部恢复展开

## 9. 验证

- 新建子类型后，今日页和任务表出现缩进子组
- 折叠父组后子组一起消失
- 多选任务后，任务出现在该类型下，原类型计数减少
- 拖动类型到目标行中间后，层级和缩进正确
- 拖到行上下边缘可调整同级顺序
- 尝试删除非空类型被拒绝并提示
- 重启后类型树、名称、颜色和顺序都保留
