# 使用任务表

> 类型：操作指南
> 状态：稳定
> 适用版本：v0.1.9+
> 相关：reference/grid.md、reference/domain-functions.md

适用：查历史、补打卡、改状态、写备注、筛选、缩放、横向滚动。

---

## 1. 找到某一天

- 打开任务表默认定位今天
- 横向滚动查看历史/未来
- `Shift + 滚轮` 横向滚动
- 顶部「今天」按钮回到今天
- `Home` 键回到今天

## 2. 补打卡 / 改状态

1. 右键或双击格子。
2. 选择「完成 / 漏打 / 跳过 / 清除」。
3. 可同时填自由值和备注。
4. 点保存。

单击只聚焦，不写库。

## 3. 写备注

- 悬停已判定格，右上角出现 `✎`
- 或右键/双击打开同一编辑器
- 有备注的格子常驻黄点

## 4. 筛选

- 类型：全部 / 自愿 / 被迫
- 单任务
- 起止日期
- 「清除」恢复全部

筛选状态禁用拖拽；没有匹配任务时显示空态。

## 5. 缩放 / 模式

- `Ctrl + 滚轮` 缩放，范围 14–44px
- 小于 24px 自动进概览
- 概览点击色块：回到详细模式并居中该日期
- 「详细 / 概览」按钮手动切换

## 6. 折叠 / 排序

- 组头可折叠
- 「已停用」默认折叠
- 改过名的任务：当前名称一行，历史名称默认折叠；点名字右侧的 `▸ N` 展开
- 历史名称行置灰，悬停可看日期范围；范围外的格子不可点
- 拖拽只在本组内排序；同一任务的多个名称段一起移动
- 跨组拖拽不生效

## 7. 键盘

| 键 | 行为 |
|---|---|
| `←/→` | 切日期 |
| `↑/↓` | 切可见行 |
| `Space` | 当前格循环状态 |
| `Home` | 回到今天 |
| `Esc` | 取消焦点 |

## 8. 验证

- 改状态后今日页/挂件/统计同步
- 缩放值重启保留
- 停用任务历史可见但不可点
- 筛选后横轴范围正确
