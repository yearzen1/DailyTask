# 日常使用：今日页与挂件

> 类型：操作指南
> 状态：稳定
> 适用版本：v0.1.9+
> 相关：reference/checkins.md、reference/windows-and-tray.md

适用：每天打卡、看剩余任务、处理到期待办。

---

## 1. 打卡

1. 打开「今日」页。
2. 点击任务行左侧方框。
3. 状态按 `pending/skipped → done → missed → 清除` 循环。

有截止日期的任务，名称右侧会显示「还差 N 天」；截止当天显示「今天截止」，次日任务不再出现。

想直接打叉或跳过：

- 右键任务行 / 点行尾 `⋯`
- 选「未完成 / 今天不做 / 清除」

## 2. 记录值

1. 点击任务名右侧的值 chip（没有值时悬停出现「＋值」）。
2. 输入 `1`、`30min`、`4/3/2/2` 等。
3. `Enter` 或失焦保存，`Esc` 取消。

值不是状态；没有判定时写值会自动记为完成。

## 3. 取消「今天不做」

1. 找到已跳过的任务。
2. 右键 →「取消」，或再点一次状态框。

## 4. 处理到期待办

今日页底部显示：

- 逾期待办：红条 +「逾期 N 天」
- 今天到期：黄色「今天」

组头显示 `已完成 / 到期总数`，并计入顶部完成率。点击待办行即可完成；当天完成的待办保留并显示勾选与删除线，再点一次可取消，次日自动移除。

点组头可折叠 / 展开待办区块；折叠后仍保留黄竖条、标题和 `x / n`。

## 5. 挂件

- 单击任务行：状态循环
- 点击值 chip：行内改值
- 右键 / `⋯`：状态菜单
- 点待办行：完成
- 点自愿 / 被迫 / 待办组头：折叠 / 展开
- 收起成胶囊再展开后，三个区块自动恢复展开
- 标题区悬停：展开主窗 / 置顶 / 收起
- 托盘左键：主窗 + 挂件一起显示
- 托盘右键：单独显示/隐藏主窗或挂件

## 6. 验证

- 主窗和挂件状态一致
- 已完成任务在今日页变灰
- 挂件宽度不够时任务名截断，但不影响点击

## 7. 常见问题

- 勾选没反应：确认点的是任务行，不是值输入框。
- 挂件不见了：托盘左键或右键「显示挂件」。
- 日期不对：检查设置里的一天起始时间。
