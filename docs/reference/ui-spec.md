# UI 规格

> 类型：参考
> 状态：稳定
> 适用版本：v0.1.9+
> 相关：reference/windows-and-tray.md、reference/grid.md、reference/i18n.md

---

## 1. 主窗口

- 左侧导航 200px + 右侧内容区
- 内容区 padding 24
- 六个视图：今日、任务表、待办、任务管理、统计、设置
- 任务行高 34px，勾选框 22×22，圆角 6
- 进度环 96px，描边 8

## 2. 今日

- 进度卡：进度环、已完成/总数、百分比、剩余、自愿/被迫/待办分项
- 完成率含今日到期待办；托盘使用同一口径
- 任务卡：自愿 / 被迫分组，组头计数
- 待办卡：逾期在前，今天在后；当天完成的待办保留并显示勾选，次日移除
- 任务行：状态框、名称、截止日期 + 倒计时、值、今天不做
- 截止 chip 合并日期与倒计时：`11/20 · 还差 5 天`，当天截止为 `11/15 · 今天截止`
- 待办行同样合并：`11/10 · 逾期 5 天` / `11/15 · 今天`
- 三个组头都可整行点击折叠；折叠后保留标题与 `x / n`
- 待办组头左侧使用 warning 黄竖条，与自愿绿、被迫蓝区分
- 待办标题过长时换行，不省略
- 内容独立滚动，左侧导航固定

## 3. 任务表

详见 [grid.md](grid.md)。

- 日期做列、任务做行
- 双行 sticky 表头 + sticky 任务列
- 月份 pill 跟随滚动
- 今天列高亮

## 4. 待办

- 顶部快速新增：标题 + 截止日期（`Enter` 保存，`Shift+Enter` 换行）
- 输入草稿在本次运行内跨视图保留；创建成功才清空，失败保留
- 分组：逾期 / 今天 / 本周 / 以后 / 已完成
- 行：完成圆圈、标题、日期 + 逾期/今天/未来倒计时合并 chip
- 无截止日期显示中性「无截止」chip
- 标题过长或含换行时自动换行，不用省略号
- 行尾按钮：`✎`、日历、`✕`
- 日历按钮直接弹出日历，点日期立即保存，底部可清除
- 右键菜单：改日期、清除日期、删除

## 5. 任务管理

- 列：任务 / 类型 / 启用日期 / 截止日期 / 状态 / 操作
- 状态：进行中 / 未开始 / 今日为止 / 即将停用 / 已停用
- 操作：停用或重新启用 / 编辑 / 删除
- 多段区间只显示最新一段，用「N 段」角标

## 6. 统计

- 列：任务 / 当前连续 / 近 30 天
- 进度条 + 百分比
- 底部口径说明

## 7. 设置

- 外观：主题、语言
- 行为：自动结算、一天起始时间
- 窗口：置顶、开机自启
- 数据：导出 / 导入
- 更新：当前版本、检查更新、安装并重启

## 8. 视觉 token

- 颜色、间距、圆角、阴影全部来自 `src/ui/tokens.css`
- 主色：自愿绿、被迫蓝、未完成红、警告黄
- 挂件复用主窗 `surface / border / text / muted`
- 禁止裸写十六进制与魔法数

### 8.1 公共组件

- `Chip`：日期 / 截止 / 逾期 / 成功 / 信息 / 中性六种语义；主窗 18px，挂件 16px
- `MenuSurface`：应用内浮层菜单统一外壳，含标题、菜单项、分隔线、危险项
- 行内操作分级：勾选和名称常显；值、改名、日期、删除 hover / focus 才出现
- 挂件与主窗使用同一套语义色，只降低尺寸和间距

## 9. 交互通用

- 删除统一二次确认
- 日期输入统一 `DateField`
- 文案全部走 `t()`
- 危险操作失败保留弹窗并显示错误
