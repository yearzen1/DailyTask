# 任务表网格

> 类型：参考
> 状态：稳定
> 适用版本：v0.1.9+
> 相关：reference/domain-functions.md、how-to/use-the-grid.md、how-to/testing.md

---

## 1. 结构

- CSS Grid / 横向虚拟化；任务列 sticky 左侧，日期行 sticky 顶部
- 任务列宽度按最长任务名（含历史名称段）自适应（160–320px）
- 日期列宽度按该列最长自由值自适应（缩放值为下限，320px 上限）
- 左上角双冻结角：任务 / 日期
- 表头两行：月份带 22px + 日期/星期 34px
- 月份文字固定在任务列右侧，随滚动换月
- 可见区 = 内容宽 − 160px 任务列；详细模式约 21 列，概览约 42 列
- 打开时定位今天，右侧留 3–4 天；`Home` 随时回到今天

## 2. 日期轴

```text
start = min(最早区间启用日, today − 365)
end   = max(today + 30, 最晚区间启用日)
上限   = 1200 列
```

超出上限时只从左侧截断，保证今天和未来 30 天始终在轴内。

## 3. 虚拟化

- 只做横向虚拟化；5–15 行不纵向虚拟化
- 渲染可视窗口 ±2 屏，左右 spacer 补齐总宽
- 表头与任务行共用同一个窗口，sticky 仍成立
- 滚动事件用 rAF 合并，每帧最多一次 setState
- 性能目标：1200 列 × 15 任务，DOM ≤ 2000 格，首屏 < 150ms，无 >16.7ms 长任务

## 4. 缩放与模式

- `Ctrl + 滚轮`：`cellSize ∈ [14, 44]`，默认 32
- 详细模式下日期列自动加宽到该列最长自由值所需宽度，`cellSize` 只作为最小宽度
- 自动宽度上限 320px；超过上限的文字在格子内换行，行高随内容增长
- 同一日期列所有行共享同一列宽；任务列所有行共享同一任务列宽
- 写回 `settings.gridZoom`
- `cellSize < 24` 自动概览
- 概览色块：✓ 实心绿 / ✗ 半透明红 / – 灰蓝 / ▫ `--color-na`
- 概览点击：回到 32px，并以该日期为中心
- `Shift + 滚轮`：横向滚动
- 页脚提示：`Ctrl + 滚轮缩放 · Shift + 滚轮横滚`

## 5. 分组与排序

- 自愿 / 被迫 / 已停用
- 已停用组默认折叠，展开后历史可见但格子 disabled
- 组头可折叠，显示**任务数**（不是名称段行数）
- 一个任务改过名后，一行 = 一个名称段；当前名称段常显，历史段默认折叠
- 当前名称段名字右侧显示 `▸ N` 按钮，展开后历史段以 `↳` 置灰显示，悬停可看日期范围
- 历史段不覆盖的日期显示 `none`，不可点
- 拖拽只在同组内排序，跨组不生效；同一任务多个名称段按任务去重
- 排序展开成全局 `sort_order` 后一次写库

## 6. 格子

- 五态：`done / missed / skipped / pending / none`
- 今天列绿底只覆盖 `pending / done / missed`；`skipped` 与区间外 `none` 保持自己的底色，不被染绿
- 区间外 / 非周期日 / 名称段外 → `none`，显示 `▫`，不可点
- 自由值：详细模式有值时用值替换符号；列宽按该列最长值自适应，不截断
- 自由值超过 320px 列宽时换行显示，行高自动增高
- 概览模式保持统一窄列，不启用自适应宽度
- 单击只聚焦；右键或双击打开编辑器
- 编辑器：完成 / 漏打 / 跳过 / 清除 + 自由值 + 备注
- 保存顺序：状态 → 值 → 备注
- 备注：悬停已判定格出现 `✎`；有备注常驻黄点

## 7. 键盘

| 键 | 行为 |
|---|---|
| `←/→` | 切日期 |
| `↑/↓` | 切可见行 |
| `Space` | 当前格循环状态 |
| `Home` | 回到今天（筛选范围外时去最近边界） |
| `Esc` | 取消焦点 |

## 8. 筛选

- 类型：全部 / 自愿 / 被迫
- 单任务
- 时间段：起止日期，裁剪日期轴
- 筛选态禁用拖拽
- 空态提示清除筛选

## 9. 日期字段

所有日期输入统一用 `ui/DateField`：

- 接受 `yyyy-mm-dd` / `yyyy/mm/dd` / `yyyy.mm.dd`
- 非法输入回退
- 应用内弹层：滚轮切月、年月实时更新、`min/max`、今天、清除、Esc、点外关闭
- 已替换待办、任务管理、任务表筛选共 8 处原生日期输入
