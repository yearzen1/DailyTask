# 任务管理表格列宽拖拽

> 类型：参考
> 状态：已实现
> 适用版本：未发布
> 相关：../reference/ui-spec.md、../reference/settings.md、../how-to/manage-tasks.md

## 目标

任务管理表格的六列宽度由用户自己定：拖动表头分隔线调整左右两列，表格总宽始终等于卡片宽，列宽跨视图切换与重启保留。

## 背景

现在列宽写死在 `Manage.tsx` 的 `<colgroup>` 里（类型 92、启用 124、截止 124、状态 132、操作 190，任务列吃剩余空间）。任务名一长就被截断，而类型、日期列常年空着；用户无法按自己的内容分配空间。

## 范围

In-scope：

- 5 条分隔线（相邻两列之间）可拖动，只改线两侧的两列，宽度此消彼长，表格总宽不变
- 每列有最小 / 最大宽度，拖到极限就停住
- 双击分隔线复位左侧列，双击列头复位该列；差值由其余列按可用余量分摊
- 拖动过程中实时预览，松手才落库（一次写入）
- 列宽存 `settings.manageColumnWidths`，切视图、重启、导入导出都保留
- 手柄可被辅助技术识别（`role="separator"`）

Out-of-scope：

- 任务表（日期网格）的列宽，已有自动测宽逻辑
- 列顺序调整、隐藏列
- 键盘方向键微调

## 方案

### 数据

`settings.manageColumnWidths`：长度 6 的百分比数组，和为 100。

| 列 | key | 默认 % | 最小 % | 最大 % |
|---|---|---|---|---|
| 任务 | `task` | 20 | 11 | 60 |
| 类型 | `category` | 11 | 10 | 24 |
| 启用日期 | `start` | 15 | 11 | 30 |
| 截止日期 | `end` | 15 | 11 | 30 |
| 状态 | `status` | 16 | 13 | 30 |
| 操作 | `actions` | 23 | 22 | 40 |

- 用百分比而不是像素：卡片宽度变化时按比例缩放，不会出现某列被挤成 0，也不需要监听容器尺寸。
- 默认值按旧布局换算：832px 内容宽下约为 166 / 92 / 125 / 125 / 133 / 191，与旧宽度基本一致。
- 最小宽之和 78%，任何窗口宽度都能同时满足，不会出现无法分配的夹取。

校验规则（`sanitizeManageColumnWidths`）：

| 输入 | 结果 |
|---|---|
| 不是数组、长度 ≠ 6 | 默认值 |
| 含非有限数、或任一项 < 4 或 > 70 | 默认值 |
| 和偏离 100 超过 0.5 | 等比缩放到 100 |
| 缩放后仍越界 | 默认值 |

### 交互

- 手柄：每列右边界 8px 热区，`role="separator"`、`aria-orientation="vertical"`、`aria-label` 走 i18n；悬停与拖动时显示 2px 竖线。
- 拖动：`pointerdown` 记录起始横坐标、起始宽度、表格像素宽；`pointermove` 换算成百分比增量后夹到两侧列的 min/max；`setPointerCapture` 保证拖出表头仍能收到事件。
- 落库：`pointerup` / `pointercancel` 提交一次；写库失败走 settingsStore 的乐观回滚，列宽跟着回滚。
- 复位：双击手柄复位其左侧列，双击列头复位该列；目标列精确回到默认百分比，差值从其余列按「可增加 / 可减少的余量」比例摊销，余量不足时尽量接近。

### 边界

- 表格像素宽为 0（未挂载 / 测试环境）时忽略拖动，不产生除零。
- 拖动过程中不写库，避免每个像素一次 SQLite 写入。
- 只改相邻两列：其余四列的百分比在拖动中保持不变。

## 兼容性

- 老版本导出的 JSON 没有 `manageColumnWidths`，导入后按默认列宽处理。
- 新版本导出给老版本导入时，老版本会忽略这个未知键，不影响其它设置。
- 不需要数据迁移：设置是 key/value 表，缺键即默认值。

## 验收

| # | 操作 | 预期 |
|---|---|---|
| 1 | 向右拖「类型 / 启用日期」分隔线 | 类型变宽、启用日期等量变窄，其余四列不变，表格总宽不变 |
| 2 | 把类型拖到最小 | 到 10% 停住，再拖不再变窄 |
| 3 | 双击「状态」列头 | 状态回到 16%，差值由其余五列吸收 |
| 4 | 拖动后松手 | `settings` 表只在松手时写入一次 |
| 5 | 切到别的视图再回来 / 重启 | 列宽保持 |
| 6 | 窗口缩到最小宽 | 六列仍按比例可见，不出现 0 宽列 |
| 7 | 数据库里是坏值 | 回退默认列宽，应用正常启动 |
