## v0.1.14

- 恢复挂件常驻：启动、托盘左键和二次启动均同时显示主窗与挂件
- 关闭主窗口时只销毁主 WebView，挂件继续作为桌面快捷入口

## v0.1.13

- 主窗口与挂件改为按需创建，切换时销毁另一套 WebView
- 关闭最后一个窗口后保留原生托盘进程，托盘可重新创建主窗口
- 托盘驻留不再保留 WebView2 子进程，显著降低后台内存占用

## v0.1.12

- 今日页与挂件三个区块（自愿 / 被迫 / 今日到期待办）支持点击组头折叠，折叠后保留标题与计数
- 待办组头显示 `x / n`，新增 warning 黄竖条，与自愿绿、被迫蓝区分
- 待办计入今日完成率，今日页、挂件、托盘统一口径
- 折叠箭头移到名称右侧并放大
- 开发构建启动时自动打开 DevTools

## v0.1.11

- 今日页与挂件中当天完成的待办保留显示，可再次取消完成
- 待办日历按钮改为直接弹出日历，点日期立即保存
- 待办、今日、挂件中的待办标题支持换行，不再省略
- 待办新增与重命名支持 `Shift+Enter` 换行
