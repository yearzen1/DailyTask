组件规范 本次整理沉淀出的可复用规则，后续 React 落地按这里执行

Chip

高度主窗 18 / 挂件 16，圆角 pill，11px 600。语义固定，不再每个页面手写颜色。

11/20 11/20 · 还差 5 天 11/10 · 逾期 5 天 进行中 被迫 无截止

规则： 日期和倒计时合并；今天截止用 warning；逾期用 danger；无截止用 neutral。

按钮

主按钮只给“添加 / 保存 / 新建”；次按钮描边；危险操作红色文字，不用红色填充。

主窗按钮高 28，挂件操作高 18–24；焦点态统一 --focus-ring。

菜单

应用内菜单统一 216px、padding 6、菜单项 28；首行显示对象名称；危险项单独分隔。

预约体检

挂件任务菜单宽 148、项高 24；胶囊右键走系统原生菜单。

行内操作

勾选和名称常显；值、改名、日期、删除 hover / focus 才出现。危险操作永远最后。

✓ 跑步 11/20 · 还差 5 天

行高主窗 34 / 挂件 26；主窗勾选 22×22，挂件 17×17。

行密度

同一套语义，两档密度。挂件只缩尺寸，不缩信息层级。

✓ 主窗任务行 11/20 · 还差 5 天 34px
✓ 挂件任务行 30 分 26px

状态与颜色

只使用 tokens.css 的语义色，不新增裸色值。

自愿 / 完成 被迫 未完成 / 危险 截止 / 警告 中性 / 已停用

今天列、选中导航等大面积底色统一用 color-mix(... 8–10%)，不叠加第二种强调色。
