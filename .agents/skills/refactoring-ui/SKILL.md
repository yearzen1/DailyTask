# Refactoring UI

一套给"会写代码但没有设计背景"的人的界面判断力。核心不是审美天赋，是三条可执行的事实：

1. **层级先于装饰。** 界面难看，八成不是配色或字体选错，是所有元素在抢同一份注意力。
2. **体系先于选择。** 无约束时"正确的选择永远不止一个"，所以你会在 120px 和 125px 之间耗掉一小时。先把选项限制成 8 个，再挑。
3. **弱化比强调便宜。** 想让一个东西突出，先让周围的东西退后，而不是继续给它加装饰。

## 适用 / 豁免

**生效**：新建界面外观、把现有界面改好看、设计评审（截图 / 代码 / 在线页面）、设计系统 token 决策、单个组件视觉优化。

**豁免**：后端与数据库、业务逻辑正确性、纯 API/平台能力问题、性能瓶颈归因。能与 `modern-web-guidance` 分工时：**视觉与信息设计归本 skill，平台 API 与现代 Web 写法归那个 skill。**

## 工作方式

写作前先确认是在哪个阶段，两个阶段要的东西完全不同：

| 阶段 | 该做的 | 不该做的 |
|---|---|---|
| 探索 | 从一个真实功能开始，不从导航外壳开始；灰度草图、快速试布局 | 抠阴影、选字体、上颜色 |
| 落地 | 先定 token（间距/字号/色板/阴影），再写组件 | 边写边临时编数值 |

三个纪律：**别设计太多**（只做能交付的最小版本，锦上添花的功能晚点再设计）、**小步循环**（做出来再修，比空想所有边界情况容易）、**当个悲观派**（默认功能很难做，别在界面里预留还没实现的入口）。

## 工作流 A：新建界面

按顺序问，每一步都有产出物，不要跳：

1. **定个性**（30 秒）：优雅/经典 → 衬线；活泼 → 圆润无衬线；中性 → 朴素无衬线。圆角大=活泼、无圆角=正式、小圆角=中性，**全站只用一种圆角策略**。文案语气同样属于个性。
2. **定四套 token**：间距阶梯、字号阶梯、色板（灰 + 主色 + 强调色）、阴影 5 档。数值见下节，直接复制。
3. **灰度布局优先**：只用间距、字号、字重、灰阶搭出层级。撑得住，加颜色是锦上添花；撑不住，加颜色只会更乱。
4. **按层级分配交互**：每页一个 primary 操作，若干 secondary，其余 tertiary。
5. **收尾**：空状态、加载/错误态、边框清理、背景装饰 —— 见 `references/depth-polish.md`。

## 工作流 B：设计评审

按固定顺序扫描（顺序即优先级，前面的问题会让后面的修复白做）：

`层级 → 间距与尺寸 → 字体排版 → 色彩 → 层次感 → 打磨细节`

每条问题按下面格式给，**必须落到具体数值或 CSS**，不许写"再大一点/柔和一些"：

```
[P0] 卡片标题 14px 加粗、正文 14px 常规，两者几乎同重
     违反：层级靠字号，而未同时调动字重与颜色
     处方：标题 16px/600 + 中性 900；正文 14px/400 + 中性 600
```

优先级定义：**P0** 破坏层级或可读性（同权重竞争、彩色背景用灰字、行长超 75 字符、正文对比度 < 4.5:1）；**P1** 体系不一致（随手编的间距/字号、阴影档位混乱、混用圆角）；**P2** 打磨与个性（空状态、边框过多、背景平淡）。

评审输出顺序：先给 3 条以内 P0，再列 P1/P2 表格，最后一句说明改完后预期效果。用户只要改法时，直接给代码 diff，别写长篇分析。

## 四套 token（可直接抄）

### 间距与尺寸阶梯

相邻两档差距 **≥ 25%**，小端密、大端疏。4px 起步、16px 为基准：

```
4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96 · 128 · 192 · 256 · 384 · 512 · 640 · 768
```

规则：所有 margin / padding / gap / 宽高都从这串里取。需要"再大一点"时取下一档，不要编 20px、28px、36px。留白先给足，**减少留白是一个需要理由的决定**。

### 字号阶梯

同一个小端密、大端疏的 1.2–1.33 倍数列，**禁用 em 定字号**（嵌套会算出阶梯外的值），用 px 或 rem：

```
12 · 14 · 16 · 18 · 20 · 24 · 30 · 36 · 48 · 60 · 72
```

界面上通常只出现 3–4 种字号；12px 是下限，再小改用颜色弱化而不是缩字号。

### 色板

每色 **9 级（100–900）**，500 为基色（≈按钮底色），100 给染色背景，700+ 给文字：

| 级别 | 100 | 200 | 300 | 400 | 500 | 600 | 700 | 800 | 900 |
|---|---|---|---|---|---|---|---|---|---|
| 彩色 L% | 96 | 90 | 82 | 72 | 62 | 52 | 42 | 32 | 20 |
| 灰 L% | 95 | 90 | 82 | 72 | 60 | 48 | 38 | 28 | 18 |

- **基色**：选一个直接能当按钮背景的色阶，不要迷信"从 50% 明度开始"。
- **两端**：最深档按"最深文字"挑，最浅档按"最浅染色背景"挑，再补 700/300、然后 800/600/400/200。
- **饱和度补偿**：明度每偏离 50% 十个百分点，饱和度 +5–8；极浅/极深再加 15–25，否则色阶发灰。
- **灰不是纯灰**：加 5–15% 饱和度。冷灰 hue 200–220，暖灰 hue 30–50，浅深档同步加，否则色温断层。
- **改亮度优先想色相**：朝亮色相（60/180/300）转=变亮，朝暗色相（0/120/240）转=变暗，**单次旋转不超过 20–30°**。
- 禁止用 `lighten()/darken()` 现场生成色阶，那会造出 35 个看起来一样的蓝。

### 阴影 5 档（双层）

双层各司其职：外层大而柔 = 直射光投影范围；内层小而紧 = 贴边环境光遮蔽。元素越高，内层越轻。

```css
--shadow-xs: 0 1px 2px rgba(0, 0, 0, .10), 0 1px 3px rgba(0, 0, 0, .10);
--shadow-sm: 0 1px 2px rgba(0, 0, 0, .08), 0 4px 8px -2px rgba(0, 0, 0, .10);
--shadow-md: 0 2px 4px rgba(0, 0, 0, .06), 0 12px 20px -4px rgba(0, 0, 0, .12);
--shadow-lg: 0 4px 6px rgba(0, 0, 0, .04), 0 24px 40px -8px rgba(0, 0, 0, .16);
--shadow-xl: 0 8px 12px rgba(0, 0, 0, .02), 0 40px 72px -16px rgba(0, 0, 0, .22);
```

分配：按钮/输入框 `xs–sm`；卡片 `sm`；下拉/浮层 `md`；抽屉 `lg`；弹窗 `xl`。交互时 hover 升一档、active 降到 `xs` 或去掉阴影。

### 字体排版默认值

| 项 | 值 |
|---|---|
| 行高 | 与字号**反比**、与行长**正比**：12–14px→1.5–1.6；16–18→1.5；20–24→1.4；30–36→1.25；48+→1.1–1.2 |
| 行长 | 20–35em（45–75 字符）；混排时正文单独限宽，容器可以更宽 |
| 字重 | 正文 400/500，强调 600/700；**不用 < 400** |
| 文字颜色 | 最多 2–3 个层级：900 主 / 600 次 / 400 三级 |
| 大标题字距 | `-0.01em ~ -0.02em` |
| 全大写字距 | `+0.05em ~ +0.1em` |

## 12 条铁律（症状 → 处方）

| # | 症状 | 处方 |
|---|---|---|
| 1 | 所有元素一样重要 | 先弱化次要项，再考虑强调重点 |
| 2 | 层级只靠字号，主次都过大/过小 | 同时调动字重与颜色，字号只承担部分差异 |
| 3 | 彩色背景上放灰字或半透明白字 | 从背景色出发手调同色相、低对比的新颜色 |
| 4 | 每条数据都挂"标签：值" | 能靠格式/上下文识别就删标签；否则合并成"还剩 12 件" |
| 5 | h1 就做得巨大 | 视觉层级与语义标签解耦，区块标题常常更像标签 |
| 6 | 图标比旁边文字抢眼 | 给图标降对比度；细边框太弱就加粗而不是加深 |
| 7 | 所有按钮同等样式 | primary 实心高对比 / secondary 描边或浅底 / tertiary 文字链接 |
| 8 | 破坏性操作默认大红粗 | 按层级放；确认步骤里它才是 primary |
| 9 | 界面填满整个屏幕 | 需要 600px 就用 600px；宽了改分栏，不要硬拉伸 |
| 10 | 文字行太长，读到串行 | 正文限 20–35em，行高随行长增加 |
| 11 | 到处加边框区分元素 | 依次试：阴影 → 相邻背景色差 → 加大间距 |
| 12 | 界面平、没有纵深 | 上亮下暗 + 向下小阴影（凸起）；浅于背景=浮起，深于背景=凹陷 |

## 交付前自检

- [ ] 一屏之内，视线是否 1 秒内落到最重要的元素上
- [ ] 文字颜色 ≤ 3 种，字重 ≤ 2–3 种，字号 ≤ 4 种
- [ ] 所有间距/尺寸都来自阶梯，没有 5、10、13、18、27 这类值
- [ ] 正文对比度 ≥ 4.5:1（大字 ≥ 3:1），彩色背景上没有灰字
- [ ] 行长 ≤ 35em，长段落没有居中，表格数字右对齐
- [ ] 阴影最多 5 档，且每处阴影能说出它对应的高度
- [ ] 每页只有一个 primary 操作
- [ ] 空状态有插画/说明/行动号召，无用的筛选器已隐藏
- [ ] 圆角策略全站一致
- [ ] 灰度截图下层级依然成立（把页面转灰度自检）
