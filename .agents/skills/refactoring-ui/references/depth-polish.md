# 层次感与收尾打磨（Depth & Polish）

## 模拟光源：光从上方来

凸起元素（按钮、卡片）：

```css
/* 上沿更亮：手调的同色相浅色，不要用半透明白（会吸走饱和度） */
box-shadow: inset 0 1px 0 rgba(255, 255, 255, .15);
/* 下方小范围深色阴影，只出现在下侧，模糊半径几个像素就够 */
box-shadow: 0 1px 2px rgba(0, 0, 0, .10);
```

内凹元素（输入框、凹槽、复选框）：

```css
/* 下沿更亮（朝向天空）+ 顶部内阴影（上方边檐挡光） */
box-shadow: inset 0 -1px 0 rgba(255, 255, 255, .08),
            inset 0 1px 3px rgba(0, 0, 0, .12);
```

- 现实里的阴影边缘相当锐利，别用夸张的大模糊。
- 浅色档要手挑，不要叠半透明白。
- **别玩过头**：追求照片级真实会让界面变乱；借一点线索就够。

## 阴影 = 高度

模糊小、范围小 → 贴近背景；模糊大、范围大 → 离用户近、更抓注意力。

| 高度 | 组件 | token |
|---|---|---|
| 贴地 | 输入框、静置按钮 | `xs` |
| 略浮起 | 卡片、抬起的按钮 | `sm` |
| 浮层 | 下拉、popover、tooltip | `md` |
| 抽屉/侧板 | drawer、侧滑面板 | `lg` |
| 模态 | modal、dialog | `xl` |

**交互联动**：hover 升一档；active 降到 `xs` 或去掉（像被按进去）；拖拽中的列表项临时升到 `lg`。想阴影该多大时，先问"它该在 z 轴哪一层"。

### 双层阴影

- 外层：大偏移 + 大模糊，模拟直射光投下的影子 → 负责"范围"。
- 内层：小偏移 + 小模糊 + 更暗，模拟贴边处环境光照不到的区域 → 负责"贴边清晰"。
- **越高，内层越轻**；最高档时内层几乎不可见（物体离桌面越远，接触阴影越淡）。

```css
--shadow-xs: 0 1px 2px rgba(0,0,0,.10), 0 1px 3px rgba(0,0,0,.10);
--shadow-sm: 0 1px 2px rgba(0,0,0,.08), 0 4px 8px -2px rgba(0,0,0,.10);
--shadow-md: 0 2px 4px rgba(0,0,0,.06), 0 12px 20px -4px rgba(0,0,0,.12);
--shadow-lg: 0 4px 6px rgba(0,0,0,.04), 0 24px 40px -8px rgba(0,0,0,.16);
--shadow-xl: 0 8px 12px rgba(0,0,0,.02), 0 40px 72px -16px rgba(0,0,0,.22);
```

## 扁平设计也要有层次

- **用颜色**：比背景浅 = 浮起，比背景深 = 凹陷（同色相不同色阶尤其明显）。
- **用实心阴影**：不模糊、仅垂直偏移，例如 `box-shadow: 0 4px 0 hsl(var(--c-700))`，保留扁平风格又有高度。
- **用重叠**：让卡片跨在两个背景的交界处，或比父容器更高、两边溢出；小控件（轮播箭头）坐在图片边缘。
- 图片重叠时给每张图加与背景同色的"隐形边框"（`outline`/`box-shadow: 0 0 0 4px var(--bg)`），保证总有缝隙。

## 图片

- **照片质量决定整体上限**：请专业摄影或用优质图库（Unsplash 等），不要先放占位图打算回头替换。
- **图上的文字**要稳定对比度，按代价从小到大：
  1. 叠半透明蒙版（黑压暗配浅字、白提亮配深字）；
  2. 降低图片对比度（记得补偿亮度）；
  3. 给图片着色：降对比 → 降饱和 → 叠纯色 multiply；
  4. 给文字加光晕阴影（大模糊、零偏移，不是真阴影）。
- **尺寸纪律**：不放大 16–24px 画的图标（改用"图标 + 有色形状底"占大空间）；不缩小细节丰富的截图（改用小屏截图、局部截图、或画简化界面）；favicon 按目标尺寸重画。
- **用户上传**：固定容器 + `object-fit: cover` 裁切；图片与背景渗色时用轻微内阴影或半透明内边框，而不是硬边框。

## 空状态

- 依赖用户内容的功能，空状态是优先项，不是收尾项。
- 结构：插画/图形 + 一句说明 + 突出的行动号召（此时 CTA 才是 primary）。
- 用户还没创建任何内容前，隐藏标签页、筛选器、批量操作等无意义的辅助 UI。

## 少用边框

区分两个元素时按顺序试：

1. **阴影**：能勾轮廓但更轻；元素与背景色不同时效果最好。
2. **相邻背景色差**：最常见的替代方案；已经用背景色区分了就把边框去掉。
3. **加大间距**：不引入任何新元素，靠距离分组。

边框用得多，界面就显得拥挤、像表格。

## 打磨已有元素（不加新东西）

- 项目符号 → 图标（对勾、箭头、语义相关图标）。
- 引用 → 把引号放大成视觉元素并换色。
- 链接 → 自定义粗下划线，与文字轻微重叠。
- 表单控件 → 自定义 checkbox/radio，选中态直接用品牌色。
- 强调色边框 → 卡片顶部、当前导航项、提示侧边、标题下短横、整页顶条。

## 背景装饰

- 换背景色（强调单个面板 / 区分整块区域）。
- 渐变：两个色相相差 **≤ 30°**。
- 低调重复图案（Hero Patterns 等），可只沿一条边重复；对比度压低，保证可读。
- 单个几何形状或简化插画，同样低对比。

## 跳出框框

组件形态没有唯一正解：下拉菜单可以分区、多列、带图标和辅助文字；表格可以合并列、加图片、用颜色强化数据；单选组重要时可以换成可选卡片。约束很有用，但别把"我以为它只能这样"当成约束。

## 自检

- 每处阴影能否说出它对应的高度？是否只有 5 档？
- 凸起/内凹的光向是否一致（都朝上）？
- 图片上的文字在各种明暗区域都可读？
- 空状态是否有插画 + CTA，且隐藏了无用控件？
- 能否去掉至少一半边框而不损失分组？
